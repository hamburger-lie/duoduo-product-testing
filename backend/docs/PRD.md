> 版本：v0.1（MVP）
> 最后更新：2026-05-09
> 状态：草稿，待评审

---

## 1. 产品定位

### 1.1 一句话定义
**用 AI 模拟的深度消费者角色替代真人调研，帮厂家与渠道方在产品立项/选品阶段以 1–2 个数量级更低的成本拿到品类测评报告。**

### 1.2 目标用户
| 用户类型 | 典型场景 | 核心诉求 |
|---|---|---|
| **厂家**（品牌方/工厂） | 新品立项前验证概念、判断卖点是否成立 | 快速、便宜、可重复测多版方案 |
| **渠道方**（经销/直播间/达人/选品师） | 选品前判断品是否好卖、对哪类人群好卖 | 快速识别目标人群、找到推广话术 |

### 1.3 不做什么（划清边界）
- **不替代**真人小样测试、临床功效测试、合规检测
- **不承诺** 100% 准确率，定位为"决策辅助 / 早期验证"
- **MVP 阶段不做**：B 端控制台、团队协作、数据导出 API、多产品横向对比

## 2. MVP 核心目标

| 维度 | 目标 |
|---|---|
| 完成时间 | 8 周内上线小程序内测版 |
| 用户量 | 50–200 名种子用户（厂家 + 渠道方各半） |
| 单次测评时长 | 用户视角 < 5 分钟拿到完整报告 |
| 单次测评成本 | LLM 侧 < ¥2（含 100 角色） |
| 角色库 | 100 个深度美妆角色（其中 10 人工精写 + 90 半自动生成） |
| 角色记忆 | 用户单聊角色时角色须记得自己的问卷答案与之前的对话 |

## 3. 用户旅程（端到端）

### 3.1 主流程
```
打开小程序
  ↓
微信授权登录（unionid 入库）
  ↓
选择身份：厂家 / 渠道方
  ↓
新建测评 → 输入产品（文字 + 1–5 张产品图）
  ↓
系统调用多模态模型理解产品 → 自动生成 30 题问卷（用户可微调）
  ↓
用户从角色库挑选 N 个角色（默认 20，可选 5–100）
  ↓
后台并行调用 LLM 让每个角色独立答题（进度条）
  ↓
答题完成 → 生成综合测评报告（量化得分 + 关键洞察 + 角色画像分布）
  ↓
报告页支持：
  ① 查看每个角色的逐题答案
  ② 单独和某个角色对话深聊（流式打字机，角色有记忆）
  ③ 导出报告 PDF / 分享链接
```

### 3.2 用户故事（按优先级）

#### P0（必做）
1. 作为厂家，我要上传一款面霜的图片+描述，5 分钟内拿到 100 个虚拟用户的购买意愿评分，这样我能判断要不要打样。
2. 作为渠道方，我要看到"哪类人群最可能买这款品"，这样我能决定推广策略。
3. 作为用户，我要能单独和某个虚拟角色对话，让她解释为什么打 3 分而不是 5 分，这样我能挖到改进方向。
4. 作为用户，我要看到角色的完整人设（年龄、城市、收入、消费习惯、护肤诉求），这样我能判断结论是否适用于我的目标人群。
5. 作为用户，再次打开小程序时我能看到历史测评列表。

#### P1（可后置）
6. 作为用户，我要能微调系统生成的问卷题目（增删改）。
7. 作为用户，我要能自定义新角色加入私有角色库。
8. 作为用户，我要能用积分系统消费功能（充值积分 → 每次测评扣分）。

#### P2（MVP 后）
9. 多产品对比、群体辩论、A/B 概念测试、PSM 价格模型、与电商真实数据对照、企业团队版。

## 4. 关键功能详述

### 4.1 身份选择
- 首次登录强制选择"厂家 / 渠道方"，存入用户表
- 可在"我的"中切换；切换会影响：默认问卷模板、报告侧重点、推荐角色组合

### 4.2 产品输入
- 文字描述：必填，10–500 字
- 产品图：1–5 张，每张 ≤ 5MB，jpg/png
- 可选字段：品牌名、SKU 价格、上市时间、目标渠道（电商/线下/直播）

### 4.3 问卷生成
- 系统根据产品摘要自动生成 30 题，覆盖 10 个调研维度（详见 `SEEDS/survey_template.json`）
- 题型：单选、多选、1–5 分量表、开放题
- 用户可在生成后增删改（P1）

### 4.4 角色挑选
- 默认推荐 20 个（系统按产品品类智能匹配）
- 用户可自由勾选 5–100 个
- 每个角色卡显示：头像（emoji 或生成图）、姓名、年龄、城市、职业、一句话标签
- 点角色卡可看完整人设

### 4.5 角色答题（后台异步）
- 每个角色独立调用 LLM（并发 ≤ 20，受方舟限流约束）
- 进度条按"已完成 / 总数"显示
- 答题中支持取消（已扣积分按未完成比例返还）
- 平均耗时：20 角色 ≈ 90 秒，100 角色 ≈ 5 分钟

### 4.6 报告生成
- 量化部分：
  - 整体购买意愿（NPS、平均分、分布直方图）
  - 各维度雷达图（10 维度评分）
  - 价格敏感度分布
  - 目标人群分布（哪些角色画像最积极）
- 定性部分：
  - 3–5 条核心洞察（LLM 综合）
  - Top 3 卖点（被多个角色认可）
  - Top 3 痛点 / 改进建议
- 必须显式标注"AI 生成内容仅供参考"（合规要求）

### 4.7 单角色对话
- 进入角色详情页 → 看该角色逐题答案 → 底部"和 ta 聊聊"
- 流式输出（打字机效果）
- 角色"记得"自己的问卷答案、产品信息、之前的对话历史
- 单次对话上下文 ≤ 20 轮

### 4.8 积分系统（P1，先埋点不做扣费）
- 用户初始 1000 积分
- 计费规则（先定义、不强制扣）：
  - 生成问卷：扣 10 分
  - 每个角色答题：扣 1 分
  - 每轮单角色对话：扣 2 分
- 积分查询页 + 流水

### 4.9 历史测评
- "我的" Tab 列出所有历史测评
- 支持按时间、产品名搜索
- 可重复查看报告与角色对话

## 5. 非功能性需求

| 维度 | 指标 |
|---|---|
| 响应时间 | 问卷生成 < 15s；产品理解 < 8s；单角色答题 < 30s；流式首字 < 2s |
| 并发 | 同时 50 个测评任务进行中 |
| 可用性 | MVP 阶段 99%（允许凌晨维护） |
| 数据合规 | 用户数据加密存储；产品图保留 90 天；角色对话保留 180 天；可主动删除 |
| AIGC 合规 | 所有生成内容显式标注"AI 生成"；输入与输出双侧内容审核；接入算法备案（先借火山方舟） |
| 隐私 | 用户产品信息默认私有；不用作训练；角色库不含真实个人信息 |

---

## 6. 关键非目标 / 风险声明

- **不保证**虚拟角色回答与真实用户行为高度一致；公开研究显示合成消费者在定性洞察上较准、在精确价格弹性等定量上有偏差。
- **不替代**专业市场调研机构（尤其在重大投资决策中）。
- **AI 生成倾向积极**：MVP 必须强制纳入"挑剔型 / 价格敏感型 / 成分极客"等负面型角色，避免一边倒好评。
- **角色一致性挑战**：百角色场景下"千人一面"是最大产品风险，必须有自动一致性评估机制。
