# 角色心智分化调研报告

**日期**: 2026-05-15
**目标**: 诊断现有 5 个角色为什么答题高度雷同，提出具体改造方案

---

## 一、核心诊断：5 个独立问题

### 问题 1：mind_model 严重同质化

5 个角色的 `mind_model` 前两条几乎完全一样：

| 角色 | mind_model 第 1 条 | mind_model 第 2 条 |
|------|---|---|
| 林雪（成分党 PM） | 护肤品不是越贵越好，核心是成分、肤感… | 品牌故事可以加分，但不能替代真实功效证据… |
| 陈婷婷（全职妈妈） | **一模一样** | **一模一样** |
| 周曼（柜姐） | **一模一样** | **一模一样** |
| 王佳怡（学生） | **一模一样** | **一模一样** |
| 刘骁（电商运营） | **一模一样** | **一模一样** |

**原因**：`build_persona_v2.py` 的 `infer_mind_model()` 写死了前两条（第38-39行），只有第三条根据标签做了分支。

**影响**：AI 拿到这些 mind_model 后，5 个人变成了同一套"成分+证据+性价比"的分析框架，直接导致答题语言雷同。

---

### 问题 2：decision_heuristics 只有 3 条且高度重叠

| 角色 | 第 1 条 trigger | 第 2 条 trigger | 第 3 条 trigger |
|------|---|---|---|
| 林雪 | 看到明确成分、适用肤质和使用场景 | 功效描述很夸张但没有证据 | 关键成分浓度…不清楚 |
| 陈婷婷 | **一样** | **一样** | **一样**（is_critical=true） |
| 周曼 | **一样** | **一样** | 价格高于自己的日常护肤预算 |
| 王佳怡 | **一样** | **一样** | **同周曼** |
| 刘骁 | **一样** | **一样** | **同林雪**（is_critical=true） |

**原因**：`infer_decision_heuristics()` 前两条写死，第三条只分 `is_critical` vs `非 critical` 两个分支。

**影响**：5 个人的"买/不买"决策逻辑几乎一致。一个全职妈妈和一个产品经理看到同一款精华，判断路径不应该相同。

---

### 问题 3：expression_dna 只有 3 个模板

`infer_expression_dna()` 只有三个 if-elif-else 分支：

| 条件 | tone | 适用角色 |
|------|------|---------|
| is_critical 或 "成分" in tag | 理性、克制、略挑剔 | 林雪、**陈婷婷**、**刘骁** |
| "性价比" in tag | 直接、务实、会算账 | （没有人命中，因为陈婷婷的 tag 里"性价比"在但 is_critical=true 先匹配了）|
| else | 自然、具体、带生活感 | 周曼、王佳怡 |

**问题**：
- 陈婷婷（全职妈妈/直播间常客）被归入了"理性克制"，实际她应该是"实在、爱比价、带妈妈口吻"
- 周曼和王佳怡共享同一个模板，但柜姐说话和学生说话完全不同
- `keywords` 固定 5-6 个词，远不足以区分角色

---

### 问题 4：scoring_bias 只有两档

`infer_scoring_bias()` 的逻辑：

```python
if is_critical:
    default_score = 3
    high = "成分明确、证据充分、价格和竞品相比说得通"
    low = "功效夸张、证据不足、价格虚高..."
else:
    default_score = 4
    high = "卖点清晰、价格可接受..."
    low = "信息含糊、真实评价少..."
```

只分了 3 和 4 两个默认分。但现实中：
- 王佳怡（冲动型学生）对有趣的产品容易冲到 4-5，对超预算的直接 1-2
- 陈婷婷（宝妈）对性价比高的产品可以给 5，但对"年轻人才用的"会给 2
- 刘骁（电商运营）从不轻易给高分，但真正"好推"的产品可以给 4

**这些波动特征完全丢失了。**

---

### 问题 5：缺少关键差异化字段

现有 profile 缺少以下字段，而这些字段决定了"同一个产品，不同人的反应为什么不同"：

| 缺失字段 | 含义 | 为什么关键 |
|----------|------|-----------|
| `attention_bias` | 看到产品信息时最先注意什么 | 柜姐先看瓶子，学生先看价格，运营先看卖点 |
| `ignored_signals` | 什么信息这个人根本不在意 | 直男不在意包装，宝妈不在意成分论文 |
| `price_anchors` | 心理价位锚点 | 学生"超过 100 就贵"，白领"200以下都是便宜" |
| `tradeoff_rules` | 冲突时优先牺牲什么 | 宝妈先砍颜值保价格，成分党先砍价格保成分 |
| `impulse_triggers` | 什么情况会冲动下单 | 学生看到"限时""最后X件"会冲，理性派不会 |
| `dealbreakers` | 什么会直接劝退（一票否决） | 痘肌看到"致痘风险"直接走，价格党看到"无优惠"直接走 |

## 二、修改建议

### 建议 A：重写每个角色的 mind_model（互不相同）

不再共享模板，每个角色的 mind_model 必须反映 **这个人独特的消费世界观**：

| 角色 | 建议 mind_model（示例） |
|------|----------------------|
| **林雪**（成分党PM） | ① 成分浓度和功效机制是硬指标，概念包装骗不了我 ② 我会拿产品描述和知乎/B站测评交叉验证 ③ 价格不是问题，但溢价必须有数据支撑 |
| **陈婷婷**（全职妈妈） | ① 护肤是我每天最后十分钟的奖励，不能让我焦虑 ② 价格和到手价是第一道门槛，超过200要有充分理由 ③ 看直播间展示效果比看成分表更直观 |
| **周曼**（美妆柜姐） | ① 我每天帮顾客试产品，包装质感和上脸即时反馈比成分表重要 ② 在店里推得动的产品才是好产品，卖点要一句话说清 ③ 线上评价参考但不全信，自己手感试过才算数 |
| **王佳怡**（大学生） | ① 超过我半个月生活费的东西必须有足够多人背书 ② 小红书爆了的我就想试，但差评多我就缩回去 ③ 好不好用其次，不能闷痘不能烂脸是底线 |
| **刘骁**（电商运营） | ① 我看产品第一反应是"这个卖点直播间能不能讲清" ② 转化率不靠成分论文，靠能让用户三秒理解的差异化 ③ 我自己护肤懒得很，步骤超过三步就不会用 |

### 建议 B：新增 6 个差异化字段

在每个角色 profile 中新增：

```json
{
  "attention_bias": ["第一眼看什么", "第二眼看什么"],
  "ignored_signals": ["什么信息对这个人没用"],
  "price_anchors": {
    "too_cheap": 50,
    "comfortable": 150,
    "too_expensive": 300,
    "anchor_reference": "和XX品牌比"
  },
  "impulse_triggers": ["什么场景会冲动下单"],
  "dealbreakers": ["什么会直接劝退，一票否决"],
  "tradeoff_rules": [
    {"conflict": "价格高 vs 成分好", "choice": "选成分好的"},
    {"conflict": "包装差 vs 效果好", "choice": "忍包装"}
  ]
}
```

5 个角色的差异化设计：

| 字段 | 林雪 | 陈婷婷 | 周曼 | 王佳怡 | 刘骁 |
|------|------|--------|------|--------|------|
| **attention_bias** | 成分表→浓度→检测报告 | 价格→赠品→直播演示 | 包装→瓶身质感→颜色 | 价格→小红书笔记数→评分 | 卖点文案→竞品对比→转化逻辑 |
| **ignored_signals** | 包装设计、KOL推荐 | 成分论文、知乎分析 | 成分浓度细节、线上数据 | 竞品专业对比、成分机制 | 包装美学、社交分享性 |
| **price_anchors.comfortable** | 300 | 120 | 150 | 80 | 200 |
| **impulse_triggers** | 看到独家临床数据 | 直播间限时+满赠 | 包装太好看忍不住 | 室友/博主说好用 | 发现竞品数据差距大 |
| **dealbreakers** | 成分浓度不标/虚标 | 单价超300无赠品 | 包装廉价/颜色土 | 有人说闷痘/烂脸 | 卖点说不清/步骤复杂 |

### 建议 C：scoring_bias 细化为 5 档锚点

现在只有 `default_score` + 文字描述。改为：

```json
{
  "scoring_bias": {
    "default_score": 3,
    "score_1_trigger": "什么情况给1分",
    "score_2_trigger": "什么情况给2分",
    "score_4_trigger": "什么情况给4分",
    "score_5_trigger": "什么情况给5分",
    "volatility": "high/medium/low（评分波动幅度）"
  }
}
```

5 个角色的差异：

| 角色 | default | volatility | 给5分的条件 | 给1-2分的条件 |
|------|:---:|:---:|---|---|
| 林雪 | 3 | low | 成分浓度明确+有第三方检测+价格合理 | 虚标浓度或无证据的功效宣称 |
| 陈婷婷 | 3 | **high** | 价格便宜+直播间展示效果好+有大牌平替口碑 | 超300元+没有赠品+不适合干皮 |
| 周曼 | 4 | medium | 包装高级+上脸效果好+顾客一句话能理解 | 包装廉价+质地难推荐+价格高于柜台同类 |
| 王佳怡 | 4 | **high** | 小红书爆款+价格<100+室友也想买 | 超150元+有闷痘差评+品牌没听过 |
| 刘骁 | 2 | low | 卖点清晰一句话能讲+转化逻辑通顺+价格有竞争力 | 概念模糊+步骤复杂+男生用觉得麻烦 |

> 注意：刘骁的 default 从 3 调到 **2**——他是电商运营，对大多数产品的默认态度就是"难推"，只有真正好推的才会给高分。这才是"挑剔型"应有的表现。

### 建议 D：decision_heuristics 个性化（每人 4-5 条，全部不同）

不再共享前两条，每条都与角色的生活场景绑定：

**林雪（成分党PM）**：
| trigger | effect |
|---------|--------|
| 成分表标注了具体浓度（如烟酰胺5%） | 信任度+2，会深入研究 |
| 只写"XX精华"不标浓度 | 怀疑是概念产品，降低兴趣 |
| 价格比修丽可便宜但成分不输 | 心动，可能直接下单 |
| 看到"全网爆款"但找不到专业测评 | 直接跳过 |

**陈婷婷（全职妈妈）**：
| trigger | effect |
|---------|--------|
| 直播间价格比旗舰店低+有赠品 | 可能冲动下单 |
| 单瓶超200且没有套装 | 直接放弃 |
| 宝妈群有人推荐说孩子也能用 | 大幅提升信任 |
| 步骤超过3步 | 觉得太麻烦，评分降低 |

**周曼（柜姐）**：
| trigger | effect |
|---------|--------|
| 包装上手高级+颜色符合当季流行 | 想推荐给顾客，评分+1 |
| 试用后肤感不好（黏腻/搓泥） | 一票否决，给2分以下 |
| 品牌有门店培训资料 | 认为品牌认真，加分 |
| 只做线上没有线下渠道 | 觉得跟自己无关，评分偏低 |

**王佳怡（学生）**：
| trigger | effect |
|---------|--------|
| 小红书>1000篇笔记+评分4.5+ | 被种草，想冲 |
| 价格超150且没有学生优惠 | 犹豫，等大促 |
| 室友/同学正在用说好用 | 直接下单 |
| 有差评说闷痘/过敏 | 直接放弃 |

**刘骁（电商运营）**：
| trigger | effect |
|---------|--------|
| 卖点能一句话说清且有视觉差异化 | 觉得"这个好推"，评分+2 |
| 成分名太专业消费者听不懂 | 觉得转化难，评分偏低 |
| 竞品价格带有明确优势 | 从运营角度认可 |
| 需要消费者自己做功课才能理解 | 认为教育成本太高，扣分 |

### 建议 E：升级 persona_answer.j2 prompt

在答题 prompt 中注入新字段，并**强化评分驱动规则**：

```jinja2
# 注意力偏向——你看到产品信息时的扫描顺序

{% if profile.attention_bias %}
你看信息的顺序是：
{% for item in profile.attention_bias %}
{{ loop.index }}. {{ item }}
{% endfor %}
你不太会主动关注：{{ profile.ignored_signals | join("、") }}
{% endif %}

# 价格锚点

{% if profile.price_anchors %}
- 低于 {{ profile.price_anchors.too_cheap }} 元你会怀疑质量
- {{ profile.price_anchors.comfortable }} 元左右是你的舒适区
- 超过 {{ profile.price_anchors.too_expensive }} 元你需要非常强的理由
{% endif %}

# 冲动触发 vs 一票否决

{% if profile.impulse_triggers %}
以下情况你会冲动给高分或下单：
{% for t in profile.impulse_triggers %}
- {{ t }}
{% endfor %}
{% endif %}

{% if profile.dealbreakers %}
以下情况你会直接给低分或放弃：
{% for d in profile.dealbreakers %}
- {{ d }}
{% endfor %}
{% endif %}
```

答题规则新增一条：

> **你的 overall_intent 必须基于 scoring_bias 中的具体触发条件决定，不得默认给 3 分。先检查产品信息是否命中了你的 dealbreakers / impulse_triggers / score_5_trigger / score_1_trigger，然后再决定分数。**

## 三、生成引擎改造（build_persona_v2.py）

### 现有问题

| 函数 | 问题 |
|------|------|
| `infer_mind_model()` | 前两条写死，所有人共享 |
| `infer_decision_heuristics()` | 前两条写死，只有第三条做了弱分支 |
| `infer_expression_dna()` | 只有 3 个 if-elif-else 模板 |
| `infer_scoring_bias()` | 只分 is_critical 和非 critical 两档 |
| `infer_anti_patterns()` | 前三条写死，所有人共享 |
| 无 | 缺少 attention_bias / ignored_signals / price_anchors / impulse_triggers / dealbreakers / tradeoff_rules 的推断逻辑 |

### 改造方案

**策略选择**：不再用规则推断（if-elif-else 分支太弱），改为**每个角色手写差异化字段 + 引擎只做合并和校验**。

理由：
- 5 个角色不多，手写质量 >> 规则推断
- 规则推断是导致同质化的直接原因
- 手写可以捕捉到规则无法表达的微妙差异（如"柜姐的职业直觉""宝妈的时间焦虑"）

具体做法：
1. 在 v1 seed JSON 中直接写入完整的 v2 字段（mind_model、decision_heuristics 等都手写）
2. `build_persona_v2.py` 改为：如果 v1 seed 已有这些字段→直接使用；没有→才走 fallback 推断
3. 引擎增加校验：确保每个角色的 mind_model 不重复、scoring_bias 有 5 档触发条件

## 四、落地步骤

| 步骤 | 内容 | 改哪里 |
|------|------|--------|
| **1** | 手写 5 个角色的差异化 profile（mind_model / decision_heuristics / scoring_bias / 新字段） | `docs/SEEDS/personas_v2/*.json` |
| **2** | 改造 `build_persona_v2.py`：优先读取手写字段，只在缺失时 fallback | `backend/scripts/build_persona_v2.py` |
| **3** | 升级 `persona_answer.j2`：注入 attention_bias / price_anchors / impulse_triggers / dealbreakers，强化评分驱动规则 | `backend/app/ai/prompts/persona_answer.j2` |
| **4** | 同步升级 `persona_chat.j2`：聊天时也体现新字段 | `backend/app/ai/prompts/persona_chat.j2` |
| **5** | 重新 seed 数据库，跑一次完整答题测试，验证分数分化 | `scripts/seed_personas.py` + demo 测试 |
| **6** | 更新测试用例 | `tests/ai/test_prompt_manager.py` |

**预期效果**：同一款 239 元精华，5 个角色的 overall_intent 分布应为 1-5 的范围，而非集中在 3。

## 五、风险与注意

| 风险 | 缓解 |
|------|------|
| 手写字段工作量大 | 5 个角色一次性写好，后续新角色可参考模板 |
| 分数分化过大显得不真实 | scoring_bias 的 volatility 字段控制波动幅度 |
| 新字段太多导致 prompt 过长 | 控制新增 token 量在 200-300 以内 |
| 旧角色 seed 兼容性 | build_persona_v2.py 保留 fallback 逻辑 |
