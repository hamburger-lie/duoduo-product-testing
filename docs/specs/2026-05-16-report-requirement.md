## 1. 背景与目标

### 1.1 背景

测品官小程序完成 AI 角色调研后，需要将调研结论沉淀为一份可向决策者、产品负责人和运营团队交付的「测品调研总结报告」。报告应具备专业性、数据支撑和图表化呈现能力，帮助各层级用户快速判断产品去向。

### 1.2 核心原则

> 第一眼看结论，第二眼看图表，第三眼能追溯数据来源。

报告不是普通文字总结，而是「**决策型报告包**」，最终交付三类文件：

| 文件类型 | 用途 |
|---------|------|
| PPT / PDF 决策版报告 | 正式汇报，展示核心结论、图表和建议 |
| Excel / 数据看板 | 完整数据与计算逻辑，支持筛选排序 |
| 附录数据包 | 保证报告可信度，记录原始数据与说明 |

## 2. 使用对象

| 角色 | 关注重点 |
|------|---------|
| 老板 / 决策者 | 最终结论、投入产出、产品机会、风险、下一步预算 |
| 产品负责人 | 产品定位、卖点、竞品差异、用户痛点、优化方向 |
| 运营团队 | 点击率、转化率、素材表现、投放效果、用户反馈 |
| 供应链 / 采购团队 | 成本、毛利、起订量、交期、库存、品控、售后风险 |
| 客户 / 外部合作方 | 报告专业性、逻辑清晰度、结论数据支撑 |

## 3. 功能需求

### 3.1 报告整体结构（共 13 页）

| 页码 | 标题 | 核心内容 |
|------|------|---------|
| 1 | 封面 | 项目名称、报告周期、负责人、日期 |
| 2 | 执行摘要 | 调研总览 + 最值得关注的 3 个产品 + 最大风险 + 下一步建议（1 分钟可读完） |
| 3 | 核心数据总览 | 调研/测试产品数、曝光/点击/转化数据、客单价、毛利率、ROI |
| 4 | 产品综合评分排行榜 | 按综合得分排序，7 个维度分项展示 |
| 5 | 产品机会四象限图 | 横轴=市场潜力，纵轴=产品竞争力，气泡大小=利润，颜色=风险等级 |
| 6 | 重点产品单页分析 | 每个重点产品一页：核心卖点 + 数据 + 结论 + 行动建议 |
| 7 | 竞品对比分析 | 价格 / 销量 / 评分 / 卖点 / 差评关键词矩阵 |
| 8 | 用户反馈与痛点分析 | 购买动机 / 常见疑问 / 好差评原因 / 产品优化方向 |
| 9 | 测品数据复盘 | 完整漏斗（曝光→点击→加购→下单）+ 素材/渠道表现 |
| 10 | 风险评估 | 供应链 / 质量 / 物流 / 合规 / 售后 / 竞争 / 季节性风险 |
| 11 | 最终结论与产品分层 | 四类产品分层（推进 / 优化 / 观察 / 淘汰）+ 判断标准 |
| 12 | 下一步行动计划 | 产品清单 + 优化方向 + 预算 + 周期 + 负责人 + 关键指标 |
| 13 | 附录 | 数据来源 / 样本说明 / 评分模型 / 竞品链接 / 原始记录 |

### 3.2 综合评分模型（100 分制）

| 评分维度 | 权重 | 评分依据 |
|---------|------|---------|
| 市场需求 | 20% | 搜索热度、内容热度、用户讨论量、需求明确度 |
| 竞品强度 | 15% | 竞品数量、头部集中度、价格带、差异化空间 |
| 产品卖点 | 15% | 痛点匹配度、视觉吸引力、功能差异化、传播性 |
| 测试表现 | 20% | 点击率、加购率、转化率、收藏率、素材表现 |
| 利润空间 | 15% | 成本、售价、毛利率、物流成本、退货影响 |
| 供应链稳定性 | 10% | 交期、库存、品控、起订量、供货稳定性 |
| 风险因素 | 5% | 合规风险、售后风险、季节性、竞争风险 |

**综合得分 = Σ（各维度得分 × 对应权重）**

**产品分层规则：**

| 综合得分 | 判断结论 |
|---------|---------|
| 85 分以上 | 重点推进 |
| 70–84 分 | 继续优化测试 |
| 60–69 分 | 谨慎观察 |
| 60 分以下 | 暂停 / 淘汰 |

### 3.3 每个产品结论的标准输出格式

```
结论：    该产品建议归类为【重点推进 / 继续优化测试 / 谨慎观察 / 暂停淘汰】。
数据依据：综合得分 X 分，市场需求 X 分，测试表现 X 分，利润空间 X 分，风险等级 X。
原因分析：该产品在 XX 方面表现较好，但在 XX 方面存在风险，需重点关注 XX。
行动建议：建议下一步执行 XX，包括优化 XX、测试 XX、调整 XX。
```

### 3.4 必须包含的图表

| 图表名称 | 类型 | 核心用途 |
|---------|------|---------|
| 数据总览卡片 | 数字卡片 / 仪表盘 | 一眼看整体数据 |
| 产品综合评分排行榜 | 横向条形图 | 直观对比各产品得分 |
| 产品机会四象限图 | 气泡图 | 机会 vs 竞争力定位 |
| 竞品对比矩阵 | 表格 / 热力图 | 竞品差异一览 |
| 测品转化漏斗图 | 漏斗图 | 转化路径流失分析 |
| 指标趋势折线图 | 折线图 | 点击率 / 转化率 / ROI 趋势 |
| 用户痛点分布图 | 柱状图 / 词云 | 痛点类型分布 |
| 风险热力图 | 热力图 | 各产品各类风险一览 |
| 产品优先级矩阵 | 矩阵图 | 最终分层结果 |
| 下一步行动路线图 | 甘特图 | 执行计划时间线 |

## 4. 内容表达规范

- **禁止**主观表达：❌「感觉不错」「应该可以」「可能有机会」
- **使用**数据化表达：✅「数据显示……」「从测试结果来看……」「结合竞品对比……」「基于用户反馈……」「综合评分结果表明……」「因此建议……」
- 每个重要结论必须有「结论 → 数据依据 → 原因分析 → 行动建议」四段结构

---

## 5. 视觉风格要求

- **整体风格**：专业、商务、简洁、数据感强、适合汇报
- **主色调**：深蓝 / 黑灰 / 科技蓝；辅色：绿色（机会）、橙色（观察）、红色（风险）
- **背景**：白色或浅灰
- **图表颜色**：控制在 3–5 种以内
- **版式原则**：
  - 每页一个核心观点
  - 顶部放结论，中间放图表，底部放数据解读和行动建议
  - 重要数字用大号字体突出
  - 避免大段文字堆积
  - 每张图表必须有标题和一句结论解读
